# My Neovim configuration

## Key bindings

| Mode | Binding   | Description                              |
|------|-----------|------------------------------------------|
|  n   | `,ff`     | Open file finder                         |
|  n   | `,fg`     | Open live grep                           |
|  n   | `,fl`     | Locate current file in the file browser  |
|  n   | `,gf`     | Show modified files in a git repository  |
|  n   | `<tab>`   | Show buffers                             |
|  n   | `,x`      | Delete the current buffer                |
|  n   | `,X`      | Delete all buffers                       |
|  n   | `<space>` | Clear selection                          |
|  v   | `Y`       | Copy selection to the system clipboard   |
|  n   | `,e`      | Toggle the file browser                  |
